│ The checkout handler held its lock across the tax service call, so a 40ms median turned into a stall at 200 concurrent carts. The      │
│ rule: narrow the lock to the state it protects, and let the remote call happen outside it.                                             │
│                                                                                                                                        │
│ How it showed up                                                                                                                       │
│                                                                                                                                        │
│ · 80% of carts completed, the rest sat until the tax call timed out                                                                    │
│ · p99 went to 611ms while the median stayed at 41ms                                                                                    │
│ · the receipt total is computed after the deferral, so it has to rejoin                                                                │
│                                                                                                                                        │
│ See [[tax-service-latency]] for what the call actually costs.                                                                          │
